配置文件	核心含义与定位	对 Agent 运行的具体影响与底层逻辑

AGENTS.md
核心守则与系统路由
（系统的"大脑皮层"与最高宪法）
优先级绝对最高。 1. 规定思考工作流：强制 Agent 遵循"思考-行动-观察"的严密逻辑链。2. 多角色路由：在多智能体架构中，决定何时将任务移交给 Coder、Researcher 等子角色。3. 安全与强制约束：设置不可逾越的红线（如删除文件前必须询问用户）。4. 错误恢复：定义工具调用失败时的补救措施，决定了执行的成败率与专业度。


SOUL.md
灵魂与人格基调
（系统的价值观与沟通态度）
赋予 AI "人的质感"。 决定智能体的底层性格、道德准则和沟通语调（如是否幽默、是否正式）。它防止系统退化为冷冰冰的问答机器，确保面对任何话题时都能保持一致的"态度"。


IDENTITY.md
身份档案
（结构化的角色标签）
确立自我认知。 字数极少的身份标识（包含名字、代词、专属 Emoji 等）。在多智能体协同、或者需要系统快速切换"角色模板"时，提供最基础的身份锚点。


USER.md
用户画像与个性偏好
（专属定制层）
实现高度个性化响应。 记录用户习惯（时区、操作系统环境、代码风格偏好等）。系统会随着交互自动更新此文件，使回答越来越懂你。但当它与 AGENTS.md 冲突时，必须服从 AGENTS.md 的操作规范。


UserTools.md
（或 TOOLS.md）
工具集与实操指南
（物理世界的接口说明）
保障外部调用的有效性与安全性。 提供当前软硬件环境的实操细节，如 API 接口文档、终端命令规范、特定路径约定和高危操作警告。指导 Agent 如何正确"动手"做事而不搞坏系统环境。


MEMORY.md
长期记忆库
（跨周期的经验沉淀）
维持长周期上下文，防止"失忆"。 独立于按天归档的短期对话记录。这里只存储经过提炼的长期事实、项目核心目标、历史踩坑经验和规律，是 Agent 跨越数月协助你的关键上下文库。


HEARTBEAT.md
心跳机制与定时任务
（被动向主动转化的驱动器）
驱动后台自治运行。 定义 Agent 在无人干预（后台）时的周期性自检任务。例如：夜间自动压缩历史记忆、定期扫描代码库变动、整理每日待办总结等，让 Agent 拥有时间观念和主动性。


BOOTSTRAP.md
初始化引导脚本
（诞生时的第一声啼哭）
仅在首次启动时执行一次。 用于在新工作空间创建时的"破冰"对话，通过收集核心信息来生成和初始化上述的其他 .md 文件。完成建档后即刻隐退，不再消耗日常对话的 Token 预算。
