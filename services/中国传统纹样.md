# 多模态工具：中国传统纹样节点与 API 服务说明

中国传统纹样节点（`pattern_search`）收录了 100 款中国传统纹样（植物花卉、动物瑞兽、几何锦纹、云水山石、吉祥器物、文字福寿与组合纹），支持在画布上进行分类筛选、关键词搜索与随机浏览。点击可放大全屏预览，选中后作为图片与 Markdown 说明文本双输出给下游节点。

---

## 1. 节点规格与接线契约

- **类别**：多模态工具 (`multimodal`)
- **端口类型**：
  - 输出端口：`output: 'image'`（产出选中纹样图片到 `node.data.imageUrl`，同时附带详情文本到 `node.data.output`）
  - 输入端口：`inputs: ['text']`（可选接收上游文本节点的文本作为检索关键词）
- **下游锁定**：当有下级连线连接时，自动禁用更换输出操作。

---

## 2. API 微服务启动与维护

详细的服务部署与维护文档请查阅：
👉 [services/chinese-traditional-patterns/SERVICE.md](../../services/chinese-traditional-patterns/SERVICE.md)

### 快速启动
```bash
cd services/chinese-traditional-patterns
pip install -r requirements.txt
python -m uvicorn api:app --host 0.0.0.0 --port 8102
```

### 核心端点
- `GET /health`：健康检查
- `GET /categories`：获取 6 大分类
- `POST /patterns/search`：检索/筛选/随机分页
- `GET /patterns/{id}`：获取单款纹样详情及 Markdown
- `GET /static/patterns/...`：静态高清原图访问
