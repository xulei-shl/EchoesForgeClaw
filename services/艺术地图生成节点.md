# 艺术地图生成节点

基于 [prettymaps](/services/prettymaps/) 项目，通过 Python 后端服务生成艺术风格的地图图片。

## 架构

```
前端 (MapArtNode)
  ↓  POST /api/modules/bookplate/generate-map-art
后端 TS (map-art.ts)
  ↓  fetch 代理请求
Python FastAPI (api.py :8101)
  ↓  调用 prettymaps.plot()
matplotlib + OSMnx → PNG 图片
  ↓  返回图片字节
后端 TS → 落盘 runtime/{userId}/map-arts/
  ↓  返回 /static/map-arts/{userId}/{file}
前端 → 展示静态图片
```

## 启动 Python 服务

```bash
cd services/prettymaps

# 安装依赖（首次）
pip install prettymaps

# 启动服务
uvicorn api:app --host 0.0.0.0 --port 8101
```

> 需要 Python >= 3.12。prettymaps 依赖 `osmnx`、`matplotlib`、`geopandas` 等库，首次安装约需 2-5 分钟。

## 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PRETTYMAPS_API` | `http://127.0.0.1:8101` | Python 服务地址（后端 TS 使用） |
| `PRETTYMAPS_PORT` | `8101` | Python 服务端口 |

## API 端点

**生成艺术地图**

```
POST /api/modules/bookplate/generate-map-art
Authorization: Bearer <token>

{
  "lat": 48.8566,
  "lon": 2.3522,
  "query": "Paris, France",
  "radius": 0.75,
  "circle": false,
  "preset": "default",
  "figsize_width": 8.27,
  "figsize_height": 8.27
}

→ { "image_url": "/static/map-arts/1/map_art_20260819-143000_12345.png" }
```

## 可用预设

| 预设 | 说明 |
|------|------|
| `default` | 默认暖色调（10 个图层：建筑、道路、水域、绿地等） |
| `minimal` | 黑白极简（仅建筑 + 道路） |
| `macao` | 澳门风格（圆形容器，建筑三色调） |
| `tijuca` | 提居卡风格（绿/蓝/粉色系，道路粗线） |

## 节点参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 地点搜索 | 文本 | - | Nominatim 即时搜索，选中后记录 lat/lon |
| 预设 | 下拉 | Default | prettymaps 预设风格 |
| 半径 | 下拉 | 0.75 km | 地图覆盖范围（0.5 - 1.5 km） |
| 边界形状 | 切换 | 方形 | 圆形 / 方形边界 |

## 端口声明

| 输出类型 | 接受的输入类型 |
|----------|--------------|
| `image` | `text`（可连线文本节点传入地点关键词） |

## 依赖

Python 服务依赖（`pip install prettymaps` 自动拉取）：
- `osmnx` — OpenStreetMap 数据获取
- `matplotlib` — 地图渲染
- `geopandas` / `shapely` — 地理数据处理
- `opencv-python-headless` — 图像处理
- `scikit-image` — 高程数据处理
- `rasterio` / `rioxarray` — 栅格数据处理
- `elevation` — SRTM 高程数据

系统级依赖：
- `libgl1` — OpenGL 系统库（Ubuntu: `apt-get install -y libgl1`）
