# 艺术地图生成节点

基于 [prettymaps](/services/prettymaps/) 项目，通过 Python 后端服务生成艺术风格的地图图片。

## 架构

```
前端 (MapArtNode)
  ↓  POST /api/modules/bookplate/generate-map-art
后端 TS (map-art.ts)
  ↓  fetch 代理请求
Python FastAPI (api.py :8101)
  ↓  调用 prettymaps.plot()
matplotlib + OSMnx → PNG 图片
  ↓  返回图片字节
后端 TS → 落盘 runtime/{userId}/map-arts/
  ↓  返回 /static/map-arts/{userId}/{file}
前端 → 展示静态图片
```

## 启动 Python 服务

```bash
cd services/prettymaps

# 安装依赖（首次）
pip install prettymaps

# 启动服务
uvicorn api:app --host 0.0.0.0 --port 8101
```

> 需要 Python >= 3.12。prettymaps 依赖 `osmnx`、`matplotlib`、`geopandas` 等库，首次安装约需 2-5 分钟。

## 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PRETTYMAPS_API` | `http://127.0.0.1:8101` | Python 服务地址（后端 TS 使用） |
| `PRETTYMAPS_PORT` | `8101` | Python 服务端口 |

## API 端点

**生成艺术地图**

```
POST /api/modules/bookplate/generate-map-art
Authorization: Bearer <token>

{
  "lat": 48.8566,
  "lon": 2.3522,
  "query": "Paris, France",
  "radius": 0.75,
  "circle": false,
  "preset": "default",
  "figsize_width": 8.27,
  "figsize_height": 8.27
}

→ { "image_url": "/static/map-arts/1/map_art_20260819-143000_12345.png" }
```

## 可用预设

| 预设 | 说明 |
|------|------|
| `default` | 默认暖色调（10 个图层：建筑、道路、水域、绿地等） |
| `minimal` | 黑白极简（仅建筑 + 道路） |
| `macao` | 澳门风格（圆形容器，建筑三色调） |
| `tijuca` | 提居卡风格（绿/蓝/粉色系，道路粗线） |
| `barcelona` | 巴塞罗那风格（暗色街道，双色建筑，网纹绿地/水域） |
| `heerhugowaard` | 荷兰风格（暖背景，网纹绿地/水域/沙滩，双色建筑） |
| `abraca-redencao` | 巴西风格（白色建筑，彩色学校/花园/公园） |
| `cb-bf-f` | 柔和色系（米色街道，绿色公园/森林，蓝色水域） |

> `barcelona-plotter` 和 `plotter` 为 plotter 绘图仪模式专用预设，matplotlib 渲染模式下不可用，前端不暴露。

## 节点参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 地点搜索 | 文本 | - | Nominatim 即时搜索，选中后记录 lat/lon |
| 预设 | 下拉 | Default | prettymaps 预设风格（8 种） |
| 半径 | 下拉 | 0.75 km | 地图覆盖范围（0.25 - 2.0 km） |
| 边界形状 | 切换 | 方形 | 圆形 / 方形边界 |

## 端口声明

| 输出类型 | 接受的输入类型 |
|----------|--------------|
| `image` | `text`（可连线文本节点传入地点关键词） |

## 部署最佳实践

### Python 版本要求

- **推荐 Python >= 3.12，< 3.14**。`vsketch`（prettymaps 依赖）在 Python 3.14 上无可用发行版，直接 `import prettymaps` 会报 `ModuleNotFoundError: No module named 'vsketch'`。
- 若必须使用 Python 3.14，需在 `services/prettymaps/` 下创建最小桩模块 `vsketch.py`，仅提供 `Vsketch` 和 `SketchClass` 空类（matplotlib 模式下不使用 vsketch，可安全绕过）。

### 首次安装注意事项

- **依赖安装耗时较长**：`opencv-python-headless`（约 44MB）、`rasterio`（约 31MB）下载较慢，Windows 上网络中断会导致 pip 缓存损坏，表现为 `WinError 32` 文件被占用。
- **建议**：使用较大超时安装（`pip install -r requirements.txt` 超时设为 30 分钟以上），或在网络稳定时执行。如遇 `WinError 32`，清理 `%TEMP%\pip-*` 临时目录后重试。
- **跳过非必要依赖**：`requirements.txt` 中 `vsketch`、`streamlit`、`ipykernel`、`marimo`、`scikit-learn` 为开发/交互依赖，服务部署时无需安装。只安装核心依赖即可：
  ```
  pip install numpy matplotlib shapely osmnx rasterio rioxarray opencv-python-headless scikit-image elevation tqdm thefuzz IPython
  ```

### 验证启动

```powershell
# 健康检查
(Invoke-RestMethod http://127.0.0.1:8101/health).status  # 期望：ok

# 预设列表
(Invoke-RestMethod http://127.0.0.1:8101/presets/simple).presets  # 期望：包含 default, minimal, macao, tijuca
```

### 跨系统部署 Checklist

- [ ] Python 版本在 3.12 ~ 3.13 之间（或准备 vsketch 桩模块）
- [ ] `services/prettymaps/` 目录下已创建 `vsketch.py` 桩（Python 3.14 必需）
- [ ] 核心依赖已安装（见上方 pip install 命令）
- [ ] 后端 `backend-ts/.env` 中 `PRETTYMAPS_API` 指向 `http://127.0.0.1:8101`
- [ ] 防火墙放行 8101 端口
- [ ] 首次调用 `/api/modules/bookplate/generate-map-art` 前确保 OSM 数据可下载（需要外网）

## 依赖

Python 服务核心依赖（服务部署必需）：
- `osmnx` — OpenStreetMap 数据获取
- `matplotlib` — 地图渲染
- `geopandas` / `shapely` — 地理数据处理
- `opencv-python-headless` — 图像处理
- `scikit-image` — 高程数据处理
- `rasterio` / `rioxarray` — 栅格数据处理
- `elevation` — SRTM 高程数据
- `thefuzz` — 模糊匹配（预设名查找）
- `IPython` — prettymaps 内部导入

系统级依赖：
- `libgl1` — OpenGL 系统库（Ubuntu: `apt-get install -y libgl1`）
