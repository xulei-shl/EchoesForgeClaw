# 多模态工具：中国传统配色节点与 API 服务说明

中国传统配色节点（`color_search`）收录了 742 款中国传统色（黄色系、橙色系、红色系、绿色系、青色系、蓝色系、紫色系、中性色），支持在画布上进行分类浏览、冷暖/深浅筛选、关键词搜索与全屏大图预览。同时集成了 5 色智能调色板生成器，选中后作为高清色卡图片与 Markdown 方案双输出给下游节点。

---

## 1. 节点规格与接线契约

- **类别**：多模态工具 (`multimodal`)
- **端口类型**：
  - 输出端口：`output: 'image'`（产出选中传统色卡图片到 `node.data.imageUrl`，同时附带详细配色方案 Markdown 文本到 `node.data.output`）
  - 复合输出：`outputs: ['image', 'text']`
  - 输入端口：`inputs: ['text']`（可选接收上游文本节点的文本作为检索关键词，连线即自动检索）
- **下游锁定**：当有下级连线连接且已选图时，自动禁用更换输出操作以保护下游数据一致性。

### 快速启动
```bash
cd services/zhongguo-traditional-colors
pip install -r requirements.txt
python -m uvicorn api:app --host 0.0.0.0 --port 8103
```

### 核心端点
- `GET /health`：健康检查与 742 色统计
- `GET /categories`：获取 8 大色系分类与冷暖属性列表
- `POST /colors/search`：检索/分类筛选/冷暖筛选/分页/随机
- `GET /colors/{id}`：获取单款色彩详情与经典搭配方案
- `POST /colors/palette/generate`：5 色调色板生成（支持自动/近似/对比/三分/中性算法与独立色块锁定）
- `GET /static/images/...`：静态高清原图访问（PNG）
- `GET /static/thumbnails/...`：色卡缩略图访问（JPG）
