# BookForge（书海回响素材工坊）主要功能模块

> 项目定位：围绕图书/素材生成的可视化画布工作流平台。平台层提供画布、节点、流式通信、认证、历史/收藏等公共能力；业务能力以「节点」形式注册到画布，新增节点只需扩展节点模板与后端路由。

## 1. 架构分层

| 层 | 目录 | 职责 |
|----|------|------|
| 前端平台层 | `frontend/src/platform`、`frontend/src/canvas`、`frontend/src/shared` | 画布、节点渲染/连线、流式 Markdown、认证状态、通用组件 |
| 前端模块层 | `frontend/src/modules`、`frontend/src/canvas/nodes/*` | 节点 UI 与交互（AI 节点、文本工具、多模态工具等） |
| 前端管理后台 | `frontend/src/admin` | LLM/提示词/节点配置、用户、系统设置、Bifrost 管理 |
| 前端素材库 | `frontend/src/library` | 生成历史、收藏、公开画廊、Bifrost 用户侧 |
| 后端平台 API | `backend-ts/src/api`（auth/users/generations/favorites/public/annotation/feedback） | 认证、用户、生成记录、收藏、公开分享、标注、反馈 |
| 后端画布模块 | `backend-ts/src/api/canvas` | 节点执行、流式输出、节点注册表、图片/地图/检索等工具路由 |
| 后端管理 API | `backend-ts/src/api/admin` | LLM 配置、提示词、节点配置、系统设置、Agent 配置、Bifrost |
| AI 基础设施 | `backend-ts/src/infrastructure/ai`、`backend-ts/src/services/ai` | LLM/图像生成代理、SSE、pi Agent、Skill Agent、FastClaw |
| 多模态服务 | `backend-ts/src/services/multimodal`、`backend-ts/src/services/node` | 图片处理、搜索、豆瓣/维基/知乎/翻译/天气等节点服务 |
| 数据层 | `backend-ts/src/db`、`backend-ts/src/config` | Drizzle ORM、SQLite/PostgreSQL、种子数据 |

## 2. 平台层模块

### 2.1 认证与用户

- JWT 认证（`@fastify/jwt` + bcryptjs），登录/注册/用户信息接口。
- 角色：普通用户 / 管理员；管理后台路由由 `AdminRoute` 保护。
- 用户管理：管理员可查看/管理用户（`/admin/users`）。

### 2.2 画布与节点工作流

- 可视化画布：节点拖拽、连线、节点选择器、节点上下文菜单、空画布提示。
- 节点端口类型：`text` / `image` / `document`（audio/video 预留），支持复合输出。
- 节点分类：`input`、`analysis`、`generate`、`output`、`tool`、`multimodal`、`glam`。
- 节点执行模式：Skill Agent > FastClaw Agent > LLM（AI SDK）> Mock，由节点配置决定。
- 流式协议：AI SDK UI Message Stream，前端 `useChat` 消费；正文 text parts，Agent 中间步骤 `data-agent_*`。
- 画板智能助手：悬浮吉祥物助手，负责需求理解、节点推荐与辅助接线（单例挂件，不进入拾取器）。

### 2.3 节点配置与模型管理

- 节点配置（NodeConfig）：把节点模板绑定到 LLM/Agent/Skill Agent 配置，支持分组与排序。
- LLM 配置：OpenAI 兼容 API 的 baseUrl/apiKey/modelName，支持 kind（chat/text_generation/image_generation）。
- 提示词模板：按 nodeType 绑定系统提示词，管理端可编辑。
- 系统设置：Unsplash/Pixabay/NASA 等凭据与全局参数（`/admin/settings`）。

### 2.4 生成记录、收藏与公开画廊

- 生成记录（generations）：记录 nodeType、名称、阶段结果、结果 URL、状态。
- 收藏（favorites）：用户收藏生成记录。
- 公开分享（publicShares）：生成记录公开列表与详情。
- 前端页面：`/history`、`/favorites`、`/gallery`。

### 2.5 运行时图片与 GC

- 生成图片、封面、地图海报、艺术地图、检索选中图、Bifrost 预览图等以 `/static/...` 公开访问，物理文件在 `runtime/`。
- 白名单子路径防穿越，内容寻址文件长缓存，可变文件协商缓存。
- 启动后延迟首跑 + 每日运行时 GC，清理无 DB 引用的运行时文件。

### 2.6 标注与反馈

- 用户标注（userAnnotations）：对 Prompt/Skill 等资源评分、备注、标签、公开标记。
- 用户反馈：画板吉祥物表单反馈推送到企业微信。

## 3. AI 生成与分析节点

| 节点 | 类型 | 说明 |
|------|------|------|
| 图书元数据 | `book_info` | 通过豆瓣 API 按 ISBN 获取图书元数据与封面 |
| 图片分析 | `image_analysis` | 多模态模型分析封面/参考图，输出艺术风格与主题色 |
| AI 文本生成 | `text_generation` | 基于上游输入流式生成文本 |
| 图像生成 | `image_generation` | 根据提示词生成图片（藏书票等） |
| AI 对话 | `chat` | 多轮对话，可绑定 LLM 或 Agent（FastClaw/Skill Agent） |
| 文本 | `text` | 手动输入/编辑 Markdown 文本 |
| 图片加载 | `image_upload` | 上传/继承上级图片/AI 产物选择 |
| 文本聚合 | `text_aggregate` | 用占位符模板拼接多个上级文本 |
| 提示词检索 | `prompt_search` | 从 Bifrost 提示词库检索选用 |
| Skill 检索 | `skill_search` | 从 Bifrost 检索或上传本地 skill zip，传入 Skill Agent |

藏书票三阶段流程对应：ISBN→豆瓣元数据 → AI 分析生成提示词 → 图像生成。

## 6. Bifrost 提示词与技能库

- 提示词库（Bifrost Prompts）：用户侧浏览/选用提示词，管理端上传预览图与元数据。
- 技能库（Bifrost Skills）：检索/上传 skill zip，管理端维护；可传入 Skill Agent。
- 用户标注：对 Prompt/Skill 评分、备注、标签、公开。
- 预览图：`/static/prompt-previews`、`/static/skill-previews`。

## 7. AI Agent 与扩展执行

- FastClaw Agent：外部 Agent 服务配置与探测，AI 对话节点可绑定。
- Skill Agent：基于 LLM + 系统提示词 + 可选 image LLM 的执行配置，管理端配置。
- pi Agent：画布 AI 对话节点的 Agent 运行时（RPC 子进程、会话、子代理、guardrails）。
- 画板智能助手：节点推荐与辅助接线。
