# 节点侧边吸附抽屉（NodeSideDrawer）使用指南

> 本文档面向全站画布节点开发，规范**富参数控制面板**的外挂抽屉（Floating Inspector）交互模式，提供标准接入模板与踩坑防范说明，便于全站多模态节点（如 `StampCutterNode`、`BookCardNode`、`WatercolorBrushNode`、`OilPaintNode` 等）直接参考与复用。

---

## 1. 为什么使用侧边吸附抽屉？

在画布工作流（Node-based Canvas）中，多模态节点往往具备丰富的艺术渲染、排版参数或工艺设置：

| 方案 | 缺点 | 适用场景 |
| :--- | :--- | :--- |
| **全屏 / 居中遮罩弹窗** | 阻断式遮挡主视口画面，用户调参时“看不见效果”，无法实现所见即所得（WYSIWYG）。 | 一次性信息录入、文字输入、登录鉴权。 |
| **卡片内部纵向堆叠展开** | 节点高度被大幅撑长变形，破坏画布版面节奏，造成大量无效留白或极长滚动条。 | 字段极少（1~2 个简单开关）。 |
| **节点侧边吸附抽屉 (Floating Inspector)** | **无缝吸附于节点外侧，绝不遮挡主视窗**；节点保持适中尺寸，抽屉按需展开收起，调参与画面 60fps 实时联动。 | **富参数节点、多工艺滤镜、排版样式器（强烈推荐）**。 |

---

## 2. 核心架构与避坑要点（必读）

### 2.1 避坑要点：严禁将抽屉渲染在 `CanvasNode` 的 `children` 内部！

> [!CAUTION]
> **CSS 包含块与溢出裁剪（Overflow-x Clipping）陷阱**
>
> `CanvasNode.tsx` 的内容区容器自带 `overflow-y-auto overflow-x-hidden`：
> ```tsx
> {/* CanvasNode 内容区 */}
> <div className="relative z-10 p-4 flex-1 overflow-y-auto overflow-x-hidden min-h-0 flex flex-col">
>   {children}
> </div>
> ```
> `NodeSideDrawer` 是通过绝对定位外挂到卡片外侧的（`left: calc(100% + 12px)`）。
> 如果将抽屉写在 `children` 内部，其横向渲染盒**将被祖先元素的 `overflow-x-hidden` 100% 截断裁切，导致抽屉完全不可见**！

### 2.2 正确架构：通过 `CanvasNode` 的 `sideDrawer` 根级插槽传入

`CanvasNode` 专门提供了根节点级别的 `sideDrawer` 插槽（与 `actionBar` / `footer` 平级，独立于内容区），直接挂载在卡片最外层 `rootRef` 下：

```
CanvasNode (rootRef: absolute, translate3d 跟随画布)
├── 内容区 (relative, overflow-x-hidden) -> 渲染 children（主视口、选框、图片等）
├── 边框外侧右下角 -> 渲染 actionBar（操作按钮组）
├── 边框外侧右侧 -> 渲染 footer（+ 添加子节点）
└── 边框外侧侧边 -> 渲染 sideDrawer（NodeSideDrawer 抽屉，不受裁剪！）
```

当画布平移、缩放（Zoom）或节点拖拽（Drag）时，`sideDrawer` 自动跟随节点平滑联动，无需任何手动的坐标转换。

## 3. 组件 API 规范 (`NodeSideDrawer`)

平台通用组件路径：[`frontend/src/platform/components/node/NodeSideDrawer.tsx`](file:///f:/Github/EchoesForgeClaw/frontend/src/platform/components/node/NodeSideDrawer.tsx)

### 3.1 Props 列表

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `isOpen` | `boolean` | **必填** | 抽屉是否展开 |
| `onClose` | `() => void` | **必填** | 关闭抽屉的回调（点击右上角关闭按钮或按 `Esc` 键时触发） |
| `title` | `string` | 可选 | 抽屉头部主标题（如“邮票工坊”、“水彩画笔参数”） |
| `subtitle` | `string` | 可选 | 抽屉头部副标题或当前状态（如“当前: 经典灯塔”） |
| `icon` | `React.ReactNode` | 可选 | 标题前缀图标（建议使用 `lucide-react`，如 `<SlidersHorizontal size={14} />`） |
| `side` | `'right' \| 'left'` | `'right'` | 吸附方向。默认外挂在节点右侧，亦可切换至左侧 |
| `width` | `number` | `280` | 抽屉固定宽度（px），常用推荐为 `280` ~ `300` |
| `headerExtra` | `React.ReactNode` | 可选 | 头部右侧额外操作区（如一键“重置”按钮） |
| `footer` | `React.ReactNode` | 可选 | 抽屉底部固底操作栏（如“一键应用全部”按钮） |
| `children` | `React.ReactNode` | **必填** | 抽屉主体内容区（支持原生纵向平滑滚动） |
| `className` | `string` | `''` | 外层自定义类名 |

### 3.2 内置特性

1. **全面事件拦截**：内部已阻止 `onPointerDown`、`onClick`、`onWheel` 冒泡，滑动抽屉内部滑块、点击下拉框或滚动列表时，**绝不意外触发外层画布平移或节点误拖动**；
2. **键盘与无障碍无缝支持**：展开期间自动监听键盘 `Escape` 按键快捷收起抽屉；
3. **优雅的毛玻璃与立体阴影**：自带 `bg-paper/95 backdrop-blur-md border border-paper-grid/80 shadow-2xl`，纸质书卷感浓郁；
4. **最小高度保护**：内置 `min-h-[480px]`，即使宿主节点被用户压缩得极矮，抽屉依然保持舒适的操作视口。

## 4. 标准接入范式（3 步极简接入）

以开发一个带有工艺调节抽屉的节点组件为例：

### 第一步：在节点中管理开关状态与参数

```tsx
import React, { useState } from 'react';
import { SlidersHorizontal } from 'lucide-react';
import { CanvasNode } from '../../../platform/components/node/CanvasNode';
import { NodeSideDrawer } from '../../../platform/components/node/NodeSideDrawer';

export const MyCustomNode: React.FC<MyCustomNodeProps> = ({ id, ...commonProps }) => {
  // 1. 管理抽屉展开状态
  const [isDrawerOpen, setIsDrawerOpen] = useState(false);

  // 2. 业务参数状态
  const [settings, setSettings] = useState({
    blur: 0,
    contrast: 100,
    style: 'classic',
  });
```

### 第二步：封装专用的配置抽屉面板组件

```tsx
// 独立抽离或内联定义面板
interface MyConfigDrawerProps {
  isOpen: boolean;
  settings: MySettings;
  onUpdate: (patch: Partial<MySettings>) => void;
  onClose: () => void;
}

export const MyConfigDrawer: React.FC<MyConfigDrawerProps> = ({
  isOpen,
  settings,
  onUpdate,
  onClose,
}) => {
  return (
    <NodeSideDrawer
      isOpen={isOpen}
      onClose={onClose}
      title="艺术工艺调优"
      subtitle="实时渲染"
      icon={<SlidersHorizontal size={14} />}
      width={290}
      headerExtra={
        <button
          type="button"
          onClick={() => onUpdate({ blur: 0, contrast: 100, style: 'classic' })}
          className="text-[10px] text-ink-light hover:text-accent px-1.5 py-0.5 rounded cursor-pointer"
        >
          重置
        </button>
      }
    >
      <div className="flex flex-col gap-3">
        {/* 表单控件、Tab 切换、滑块等 */}
        <label className="flex flex-col gap-1 text-xs">
          <span className="text-ink-light">对比度: {settings.contrast}%</span>
          <input
            type="range"
            min={50}
            max={200}
            value={settings.contrast}
            onChange={(e) => onUpdate({ contrast: Number(e.target.value) })}
            className="cursor-pointer accent-accent"
          />
        </label>
      </div>
    </NodeSideDrawer>
  );
};
```

### 第三步：通过 `CanvasNode` 的 `sideDrawer` 插槽传入

```tsx
  return (
    <CanvasNode
      id={id}
      {...commonProps}
      // 🌟 重点：必须挂在 sideDrawer 插槽中，不可放入 children！
      sideDrawer={
        <MyConfigDrawer
          isOpen={isDrawerOpen}
          settings={settings}
          onUpdate={(patch) => setSettings((prev) => ({ ...prev, ...patch }))}
          onClose={() => setIsDrawerOpen(false)}
        />
      }
    >
      {/* 节点主体内容区 */}
      <div className="flex flex-col h-full gap-2">
        {/* 工具栏：带抽屉切换按钮 */}
        <div className="flex items-center justify-end">
          <button
            type="button"
            onClick={() => setIsDrawerOpen((prev) => !prev)}
            className={`px-2 py-0.5 rounded text-xs flex items-center gap-1 transition ${
              isDrawerOpen
                ? 'bg-accent text-white font-medium shadow-2xs'
                : 'hover:bg-paper-grid/40 text-ink-light'
            }`}
          >
            <SlidersHorizontal size={12} />
            <span>参数调优</span>
          </button>
        </div>

        {/* 节点主视口（图片/画布/输入区） */}
        <div className="flex-1 min-h-0 bg-paper-grid/10 rounded flex items-center justify-center">
          <MyLiveRenderer settings={settings} />
        </div>
      </div>
    </CanvasNode>
  );
};
```

## 5. 交互设计与 UI 最佳实践规范

在设计抽屉内部 UI 时，建议遵循以下统一规范（参考已落地的 `StampStudioPanel` 范式）：

### 5.1 紧凑 Tab 分组（避免单页过长）
参数较多时（> 5 项），顶部采用负空间分段胶囊 Tab：
```tsx
<div className="flex items-center gap-1 p-0.5 rounded-lg bg-paper-grid/30 border border-paper-grid/50 shrink-0">
  <button className={activeTab === 'basic' ? 'bg-paper text-accent shadow-2xs' : 'text-ink-light'}>
    基础
  </button>
  <button className={activeTab === 'advanced' ? 'bg-paper text-accent shadow-2xs' : 'text-ink-light'}>
    高级
  </button>
</div>
```

### 5.2 状态同步与 60fps 实时预览
- 调参过程优先使用瞬时 state 驱动左侧 Canvas / SVG / DOM 渲染；
- 当调整频率极高（如拖拽色相环、物理颗粒计算）时，建议在组件内维护本地瞬时状态，待 `onChangeEnd` 或加防抖再提交至外层 Node 数据仓库（`onUpdateState`），保障画布帧率丝滑。

### 5.3 适合复用外挂抽屉的节点候选
- **`BookCardNode`**：书影卡片封面材质、烫金反光度、浮雕景深、纸张泛黄调节；
- **`WatercolorBrushNode`**：水彩毛边扩散度、湿画法水晕、颜料颗粒沉积（Granulation）参数；
- **`OilPaintNode`**：油画笔触厚度、画布肌理（Canvas Texture）、光影凹凸高光；
- **`JournalMakerNode`**：手账贴纸纹理、胶带样式、版式留白网格；
- **`ReceiptPrinterNode`**：热敏纸划痕、做旧褶皱、出纸边缘锯齿。

## 6. 常见问题排查 (FAQ)

- **Q: 点击开启按钮后，页面 DOM 里能搜到抽屉元素，但画面上看不见？**  
  **A**: 检查是否误把抽屉写进了 `CanvasNode` 的 `children`。必须提升到 `CanvasNode` 的 `sideDrawer` prop 中。
- **Q: 抽屉盖住了右侧的「+ 添加子节点」按钮怎么办？**  
  **A**: 属于正常层级设计。抽屉处于操作态（`z-40`），拥有完整毛玻璃底色与投影，用户在专注于工艺精细调参时无需添加子节点；关闭抽屉（按 `Esc` 或点关闭）后，右侧加号与连接点即刻完全显现。
- **Q: 抽屉能否挂在节点左侧？**  
  **A**: 可以。设置 `side="left"` 即可将抽屉吸附至节点左边缘（`right: calc(100% + 12px)`）。
