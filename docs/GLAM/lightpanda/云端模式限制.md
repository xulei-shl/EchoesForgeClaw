# 云端 Lightpanda 无法访问 vufind.library.sh.cn（实测结论）

结论：**云端 Lightpanda 抓不到 VuFind 的检索页，不是解析问题，而是站点 WAF 拦了出口 IP。**
本机 Lightpanda 正常的原因是本机出口 IP 被站点信任，与 Lightpanda 版本 / UA / 渲染能力无关。

## 现象

`lightpanda.mode=cloud` 时，VuFind 馆藏节点报「未找到索书号」；切回 `local` 一切正常。

## 实测证据（2026-09-24）

同一段抓取逻辑分别走本机 CDP 与云端 CDP，抓 `https://vufind.library.sh.cn/Search/Results?...&lng=zh-cn`：

| 接入点 | HTTP 状态 | 最终 URL | 检索页内容 |
| --- | --- | --- | --- |
| `ws://127.0.0.1:9222`（本机 Lightpanda 1.0.0-nightly） | 200 | `/Search/Results?...` | 正常，「索书号」命中 |
| `wss://uswest.cloud.lightpanda.io/ws`（默认出口 `fast_dc`） | 200 | `/verification?callback=...` | 「权限验证」人机验证页，无索书号 |
| 云端 `proxy=datacenter&country=cn` | 200 | `/verification?callback=...` | 同上 |
| 云端 `browser=chrome` | 200 | `/verification?callback=...` | 同上 |
| 本机 `curl`（直连、Chrome UA） | 200 | `/Search/Results?...` | 正常，「索书号」命中 |

验证页特征（用于代码识别，见 `backend-ts/src/services/node/vufind-service.ts::isVufindChallengePage`）：

- 302 到 `/verification?callback=<原 URL>`，页面 `<title>权限验证</title>`；
- 依赖 `/verification/js/{tac,finger,surefire,jsencrypt}.min.js` 做指纹校验。

因为本机与云端的浏览器 UA 完全相同（`Lightpanda/1.0`）而结果不同，可以确定拦截判据是**出口 IP**，
不是 UA / JS 能力（云端 `browser=chrome` 同样被拦）。Lightpanda 云端目前只提供数据中心 IP
（`fast_dc` / `datacenter`，`country` 参数也仍是机房段），住宅代理需单独联系官方开通，
所以**在当前配置下云端模式无法访问该站点**。

## 馆藏不依赖浏览器（纯 HTTP 也可取，实测 2026-09-24）

详情页**主体 HTML 里没有馆藏**（只有空壳 tab：`<li class="record-tab holdings initiallyActive" data-tab="holdings">`），
馆藏由前端异步填充；但填充用的片段端点是**服务端渲染**的，纯 HTTP 直接可取：

```
GET https://vufind.library.sh.cn/Record/{id}/AjaxTab?tab=holdings&lng=zh-cn
→ 200, ~30KB, <div class="branch"> / <div class="location-item pl-5"> / <tr typeof="Offer"> / <span class="holding-field barcode">
```

`{id}` 来自检索页首条结果的 `a.title.getFull`（或任意 `/Record/{uuid}` 链接）。
同一 ISBN 下该片段解析结果与浏览器渲染路径逐字段一致（馆藏地 / 条码 / 借阅类型 / 状态），
所以 HTTP 兜底现在是「检索页 + 馆藏 tab 片段」两步，不再是「仅索书号」。

注意：`/AJAX/JSON?method=getItemStatuses` 虽存在，但对这些记录返回 `{"statuses":[]}`，取不到馆藏；
`/Record/{id}/Holdings`、`?tab=holdings` 返回的是整个详情页外壳，同样没有馆藏标记。

## 现在的代码行为

1. 浏览器路径落到验证页 → 抛普通错误，走 HTTP 兜底；HTTP 兜底从检索页静态 HTML 取索书号 + 书目 + 详情页链接，
   再请求馆藏 tab 片段解析馆藏（同 ISBN 下与浏览器路径逐字段一致，实测）；
2. HTTP 兜底也落到验证页 → 抛 `VuFindError`，提示「当前出口 IP 被拦截，请改用本机 Lightpanda」，
   不再误报成「未找到索书号」（后者会被当成藏书不存在）。

## 排查手法（复现用）

- 本机：`curl -s -o /tmp/x.html -w '%{http_code} %{url_effective}\n' -L -A '<Chrome UA>' '<检索页 URL>'`，
  看最终 URL 是否为 `/verification`、正文是否含「索书号」。
- 云端：用 `resolveLightpandaEndpoint` + `connectCdpOverProxy` 连上后 `page.goto(...)`，
  打印 `page.url()` / `page.title()` / 是否命中 `/verification/js/tac.min.js`；
  调试时可在 wss 端点后追加 `&proxy=datacenter&country=cn` 或 `&browser=chrome` 对比。

## 如果确实需要云端模式

- 让云端浏览器经中国的住宅/可信出口出网（`proxy` 参数或联系 Lightpanda 开通住宅代理），
  再让服务端出口 IP 保持在可信范围内（服务端与云端出口要同侧）；
- 如果需要云端模式：上述 WAF 拦截不影响业务输出 —— 被拦时 HTTP 兜底同样能拿到索书号 + 书目 + 馆藏，
  只是每次请求多两次 HTTP 往返（检索页约 2MB + 馆藏片段约 30KB），且拿不到浏览器特有的渲染能力。
