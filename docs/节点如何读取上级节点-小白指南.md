# 节点如何读取上级节点（小白指南）

> 用大白话解释画板里「连线」之后，每个节点会「看」哪些上级节点、拿它们的什么内容当输入。
>
> 技术细节（端口类型声明、输入收集、执行引擎）见
> [《节点输入接线（连线即输入 · 端口类型匹配）》](./节点输入输出声明式接线.md)。

---

## 一、先记住 3 条简单规则

1. **画线连上就是输入（只认直接连线的上级）。**
   节点只会读「直接连在它左边的」那些节点，**不会**隔好几层往上找。
   所以：想让某个节点用上什么数据，就把那个数据源直接连给它。

2. **连的类型不对，会有明确标注。**
   每个节点只接受「特定类型」的输入（文本 / 图片…）。连错类型的线会变成**红色**，
   节点标题旁会出现「类型不匹配」红色小标签；点运行时也会弹出提示告诉你哪里不对。
   （连线仍然可以连，只是这个输入不会被使用。）

3. **图书元数据不走连线，走开关。**
   每个可执行节点右上角 ⚙「运行设置」里有一个「包含图书元数据」开关：
   开启后，无论图书元数据节点连没连过来，都会把画布最前面的图书信息作为背景知识注入。

### 0. 怎么连线？两种方式 🖇️

- **「＋」自动连**：点节点右侧的「＋」添加子节点，父子和它自动连上线（自动排位置）。
- **手动拖线**：按住任意节点的**右侧小圆点（输出口）**拖拽，会拉出一根虚线跟随鼠标；
  松手在目标节点的**左侧小圆点（输入口）**上（或节点卡片任意位置），就创建了一条新连线。
  - 拖的时候虚线会**变色提示**：拖到能接收它的节点 → 主色实线；拖到类型不匹配的节点 → 红色。
  - 想连「图片上传 → 图像生成」这种**不是父子关系**的线，就用这个方式；
  - 自己拖的线**防重、防环**（连不上会弹提示）；连错可 **Ctrl+Z** 撤销；
  - 拖到一半不想连了，按 `Esc` 或空白处松手取消。

## 二、每个节点看重什么（总表）

| 节点 | 它需要什么 | 从哪里拿 | 会提示「运行不了」如果 |
|---|---|---|---|
| 图书元数据 | 手动输入 ISBN | ——（自己） | 没填 ISBN |
| 文本 | 手动打字 | ——（自己） | 没打字 |
| 图片上传 | 手动上传图片 | ——（自己） | 没传图 |
| 图片分析 | 参考图（可选）+ 图书信息（可选） | 直接连线的「图片上传」；⚙ 开关注入图书元数据 | 既没图也没图书封面 |
| 提示词生成 | 分析结果 / 文本 / 图书信息（有一样即可） | 直接连线的「图片分析」「文本」「AI 对话」；⚙ 开关注入图书元数据 | 上游一个能用的都没有 |
| 图像生成 | 提示词（+ 可选参考图） | 直接连线的「提示词生成」；没有时用图书信息当提示词；直接连线的「图片上传」当图生图参考；直接连线的「图片分析」/ 文本节点并入提示词上下文 | 没提示词；或连了「图片上传」却没传图 |
| AI 对话 | 图书信息（可选）+ 直接上级内容（可选） | ⚙ 开关注入根节点元数据；直接连它的上级节点的文本 / 图片输出 | 需你手动发消息（不自动跑） |
| 文本聚合 | 全部直接连线的文本输出节点 | 用你写的「模板 + {占位符}」拼起来，谁在上游就用谁 | 没连任何文本节点 |

## 三、逐个讲解

### 1. 图书元数据 💡
- **它的一生**：你输入 ISBN，它去豆瓣拉回书名、作者、封面等。
- **它读谁**：不读任何上级，它是源头。
- **谁读它**：不需要连线——别的节点在 ⚙「运行设置」里打开「包含图书元数据」就能用上它。
  直接把它连给某个节点也完全没问题（比如图片分析）。

### 2. 图片上传 🖼️
- **它的一生**：你上传一张参考图。
- **它读谁**：不读任何上级，它是源头。
- **谁读它**：直接连给「图片分析」（当分析对象）或「图像生成」（当图生图参考）；
  也可连给「AI 对话」——它会作为视觉上下文随对话一并交给模型 / Agent。
  ⚠️ 注意：它的输出是「图片」。连给只收「文本」的节点（如提示词生成）会标红不生效。

### 3. 文本 ✍️
- **它的一生**：你手动打一段文字。
- **它读谁**：不读任何上级，它是源头。
- **谁读它**：直接连给「提示词生成」（作为补充文字）或「图像生成」（并入提示词上下文）。

### 4. 图片分析 🔍
- **它读谁**：
  - 直接连线的某个「图片上传」→ 分析那张图；
  - ⚙ 开关注入的图书元数据 → 封面兜底（没连图片上传时用）。
- **参考图优先级**：自己弹窗里上传的图 > 直接连线的「图片上传」> 图书封面。

### 5. 提示词生成 ✨
- **它读谁**（三样有一样就行，都可以给）：
  - 直接连线的「图片分析」→ 艺术风格/主题色分析；
  - 直接连线的「文本」或「AI 对话」→ 补充文字；
  - ⚙ 开关注入的图书元数据 → 图书信息。
- **会提示运行不了**：上游一个能用的都没有（或连的全是图片类、类型不匹配）。

### 6. 图像生成 🎨
- **它读谁**：
  - 直接连线的「提示词生成」→ 拿它的提示词（没有它时，用图书元数据文本当提示词）；
  - 直接连线的「图片分析」/「文本」/「AI 对话」→ 并入提示词上下文；
  - 直接连线的「图片上传」→ 图生图参考图；
  - ⚙「包含图书元数据」开启时 → 图书元数据文本当提示词；
  - ⚙「加载图书封面图片」（默认开，随图书元数据生效）→ 封面图一并作为图生图参考。
- **会提示运行不了**：没提示词；或连了「图片上传」但还没传图。

### 7. AI 对话 💬
- **它读谁**：
  - ⚙「运行设置」里的「加载图书元数据」（默认开）→ 根节点图书信息；
  - ⚙「加载上一级节点内容」（默认开）→ 直接连它的上级节点的文本输出，支持对话链式串联；
  - ⚙「加载上级图片」（默认开）→ 直接连它的「图片上传」/「图像生成」节点的图片，
    随对话一并交给模型 / Agent 作为视觉上下文（你也可以在输入框直接附带图片）。
- **不会自动跑**：需要你手动发消息，多轮对话由你驱动。

### 8. 文本聚合 🧩（占位符模板）
- **它是干什么的**：把多个文本输出节点（文本 / AI 对话 / 图片分析 / 提示词生成 / 图书元数据…）
  按**你自己定的格式**拼成一段话。比如想在提示词前加自定义标题、分隔线，就用它。
- **它读谁**：直接连线的全部**文本输出**节点（连图片类会标红不生效）。
- **怎么用**（三步）：
  1. 把它连给几个文本节点；
  2. 在它的「模板」页写格式，用 `{占位符}` 引用上级——点下方来源行的「插入」按钮自动写入；
  3. 点「预览」看拼接结果（也可以直接改占位符名字）。
- **不用点运行**：上级内容一变，聚合结果自动更新；下游节点直接拿它的输出当输入。

## 四、运行时机（手动 or 自动）

- **默认手动**：节点加进画板后不会立刻跑。连好上游、填好输入后，点节点上的「▶ 运行」按钮执行。
  输入不够或类型不匹配时，会弹提示说明原因，不会默默等待。

## 五、常见 Q&A

**Q1：我把「图片上传」连给了「提示词生成」，为什么是红线？**
因为「提示词生成」只接受「文本」输入，而「图片上传」输出的是「图片」，类型不匹配。
想用图，就把它连给「图片分析」或「图像生成」。

**Q2：提示词生成怎么才能用上图书信息？**
两个办法：把「图书元数据」直接连给它；或者在它的 ⚙「运行设置」里打开「包含图书元数据」。

**Q3：图像生成不连「提示词生成」，直接连「图书元数据」行吗？**
可以。没有「提示词生成」时，会用图书元数据文本当提示词；但更推荐连「提示词生成」，让 AI 加工成更像样的绘画提示词。

**Q4：为什么我连了线，点了运行却没反应？**
看节点右上角的运行按钮有没有弹提示：① 输入类型不匹配（红线）；② 需要的上游没连或还没出结果；
③ 连了「图片上传」但没传图。按提示调整即可。

**Q5：AI 对话怎么把上游内容带进来？**
把上游节点直接连给它，⚙「运行设置」保持「加载上一级节点内容」/「加载上级图片」开启；
对话首轮会自动带上文本与图片。

**Q6：我想把两个没有父子关系的节点连起来（比如「图片上传」和「图像生成」），怎么连？**
用**手动拖线**：按住「图片上传」右侧的小圆点，拖到「图像生成」左侧的小圆点上松手即可。
（通过「＋」创建子节点会自动连线，但那只连父子；想要任意两个节点之间连线，就用拖线。）

**Q7：拖线拖到一半不想连了怎么办？**
按 `Esc` 键，或者直接在空白处松手，虚线就会消失，不会产生任何连线。

**Q8：为什么拖线连不上？**
只有**松手在目标节点左侧的输入口**上才算连上；自己连自己、连已经存在的同一对线、或连成循环
（A→B 又 B→A）都会被拒绝并弹提示。

**Q9：多个文本节点连到一个节点，怎么控制拼接格式？**
两个选择：
- **精细控制**：中间加一个「文本聚合」节点，在模板里用 `{占位符}` 自定义标题、顺序、分隔线（推荐）；
- **直接连（兜底）**：不经过聚合节点直接连多个文本节点，系统会用固定格式自动拼接（`## 标题` + 分隔线）。

**Q10：模板里的 `{xxx}` 怎么填？**
把文本节点连到「文本聚合」后，下方会**自动列出**每个上级节点的占位符（默认就是节点标题，可改名）。
点某一行右侧的「插入」，`{占位符}` 就会写进模板光标处。模板里出现但没连上对应节点的占位符，
会显示琥珀色提示提醒你处理。
