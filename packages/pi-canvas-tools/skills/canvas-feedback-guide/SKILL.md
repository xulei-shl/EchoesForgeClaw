# 工单直达企业微信

`canvas_send_feedback` 把一段结构化内容实时推送到管理员企业微信群。**组好 `title` + `content` 就调用**——工单内容来自当前对话（用户说「把这个推送微信」时，指的就是上一条回复），不去翻工作区文件、也不为写工单再发一轮确认问卷。

## 四类 `category`

| `category` | 触发场景 | `title` 前缀 | `content` 重点 |
| :--- | :--- | :--- | :--- |
| `custom_ai_node` | 用户要定制 4 类受管 AI 节点（`image_analysis` / `text_generation` / `image_generation` / `chat`） | `[节点定制申请] ` | 模型选型、System Prompt 草案、期望输入输出端口 |
| `feature_request` | 现有 33 个默认节点覆盖不到的新功能、新节点、新数据源 | `[功能建议] ` | 应用场景、期望价值、期望的输入输出形式 |
| `bug_report` | 连线标红、节点无响应、合成图缺字体、抠图白边等异常 | `[问题上报] ` | 具体现象、涉及节点、报错原文、可复现步骤 |
| `user_suggestion` | 用户主动提的体验建议与产品心声 | `[体验反馈] ` | 建议要点 + 用户原话 |

## `content` 四段式

```markdown
### 概述
[一句话说清诉求]

### 背景与场景
[用户想完成什么、卡在哪里]

### 建议方案
- 建议模型/引擎: xxx
- 建议提示词/系统设定: xxx
- 期望输入/输出形式: xxx
（不适用的小节整段省略）

### 用户原话
[用户原始关键表达]
```

## 完成判据

工具返回「反馈已成功推送」即完成。返回 `失败` / `异常` 时，把工具给出的原因原样告诉用户，并说明可以稍后重试。

## 受管节点为什么不能直接创建

`image_analysis`、`text_generation`、`image_generation`、`chat` 依赖管理员分配的后台算力配额、模型绑定与提示词模板，画布上创建空白实例无法运行。向用户说明这一点，并把梳理好的配置方案随工单一起提交——管理员据此在管理端建好节点后再让用户使用。
