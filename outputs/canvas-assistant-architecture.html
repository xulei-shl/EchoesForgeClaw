EchoesForgeClaw · Architecture Blueprint

基于 Pi Agent 的画板助手架构设计

将画板拓扑与38种节点能力封装为 Pi 扩展包，通过 AGENTS.md 准则、同捆技能知识库与 RPC Dialog 静默拦截，实现高扩展性、可撤销的大模型画布控制中枢。

Cognitive Triad
三层认知约束体系
画板助手杜绝大模型随意建节点与幻觉的关键，在于三层严密的约束协同：
  • 系统提示词 (AGENTS.md)：明确「现状感知先行」（必须先通过 canvas_list_nodes 查看画布现状，拒绝盲目清空或凭空假设）、读写分离与运行驱动规范。
  • 技能知识库 (Skills)：canvas-node-catalog 详尽定义 33 种内置节点与 4 类 AI 节点的端口契约及参数；canvas-workflow-patterns 指导优雅连线。
  • 工具契约 (promptGuidelines)：每个工具声明使用时机与依赖关系，交叉引用形成认知闭环。
Silent RPC Bridge
零侵入 UI RPC 通信桥
画布拓扑仅存在于前端 React 状态中，独立 RPC 子进程中的 Agent 无法直接访问 DOM 或状态：
  • 反向通道借道：扩展包工具执行时调用 ctx.ui.select('CANVAS_OP:...')，借由 Pi 协议原生的 UI 交互通道外发。
  • 前端静默拦截：AgentChatPanel 识别 CANVAS_OP: 前缀后不弹用户确认框，静默交由 canvasExecutor 处理。
  • 凭据代理与回传：检索操作复用前端已登录 JWT 调后端 Bifrost，避免子进程 401 鉴权失效；执行结果写回子进程 stdin 恢复推理。
Transactional Safety
命令层事务与撤销重做
保障 Agent 操作与人工交互的一致性与安全性：
  • 撤销栈对齐：所有写操作必须收敛至 canvasCommands 命令层，在修改 Store 前调用 recordHistory()，确保 Agent 创建、连线、更新、删除操作均支持完整的 Ctrl+Z 撤销。
  • 上下文经济学：只读列表只回元数据摘要；读取内容实施 20,000 字符截断，Base64 图片收敛为占位符，保护模型上下文。
  • 两段式防护：删除操作严格校验下游依赖，离开画板页面时下指令明确报错，杜绝脏写。
